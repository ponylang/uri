# uri

uri is now part of ponyc's standard library as the `uri` and `uri/template` packages.

uri was a URI library for Pony implementing [RFC 3986](https://datatracker.ietf.org/doc/html/rfc3986) parsing, reference resolution, and normalization; [RFC 3987](https://datatracker.ietf.org/doc/html/rfc3987) IRI/URI conversion and IRI-aware encoding; and [RFC 6570](https://datatracker.ietf.org/doc/html/rfc6570) URI template expansion at all four levels.

For the current code, see the [`uri` package in ponyc](https://github.com/ponylang/ponyc/tree/main/packages/uri).
